上一篇介绍了远程控制的基本概念和方案分类。本篇我们来实际体验三款主流远程控制软件：**ToDesk**、**向日葵** 和 **RustDesk**，帮你选出最适合的那一款。

## 软件概览

| 软件 | 类型 | 价格 | 特点 |
|------|------|------|------|
| **ToDesk** | 国产商业 | 免费/付费 | 国内优化好、延迟低 |
| **向日葵** | 国产商业 | 免费/付费 | 支持远程开机 |
| **RustDesk** | 开源免费 | 完全免费 | 可自建服务器 |

## ToDesk：国内体验最佳

ToDesk 是近年崛起的国产远程控制软件，主打低延迟和高画质。

### 下载安装

访问 [ToDesk 官网](https://www.todesk.com/) 下载对应平台的客户端：

- Windows / macOS / Linux
- iOS / Android
- 网页版（无需安装）

### 首次使用

1. **安装并启动** ToDesk
2. **记下设备代码和临时密码**
3. 在另一台设备上输入代码和密码即可连接

```
┌─────────────────────────────────┐
│  ToDesk                         │
├─────────────────────────────────┤
│  设备代码: 123 456 789          │
│  临时密码: abcd1234             │
│                                 │
│  [远程本设备] [连接其他设备]     │
└─────────────────────────────────┘
```

### 免费版 vs 付费版

| 功能 | 免费版 | 个人版(¥108/年) | 专业版 |
|------|--------|-----------------|--------|
| 连接时长 | 每月300分钟 | 无限 | 无限 |
| 最高画质 | 1080P | 4K@60fps | 4K@144fps |
| 同时连接数 | 1 | 3 | 更多 |
| 文件传输 | 有限制 | 无限制 | 无限制 |
| 去水印 | 否 | 是 | 是 |

### 优缺点

**优点**：
- 国内节点多，延迟低（实测 1-5ms）
- 画质好，4K 60fps 流畅
- 支持隐私屏（被控端黑屏）
- 界面简洁，易上手

**缺点**：
- 免费版限制较多（300分钟/月）
- 数据经过 ToDesk 服务器
- 闭源软件

### 适用场景

- **日常远程办公**：偶尔连接，免费版够用
- **高画质需求**：设计、剪辑等对画质要求高的场景
- **帮父母修电脑**：操作简单，教父母安装方便

## 向日葵：远程开机利器

向日葵是老牌远程控制软件，最大特色是支持**远程开机**功能。

### 下载安装

访问 [向日葵官网](https://sunlogin.oray.com/) 下载客户端。

### 远程开机功能

这是向日葵的独门绝技。需要配合硬件：

**方式一：向日葵开机棒/插座**
- 官方硬件，即插即用
- 价格 ¥79-199 不等

**方式二：主板 WOL 功能**
- 需要主板支持 Wake-on-LAN
- 需要配置 BIOS 和系统设置
- 免费但配置复杂

```
┌───────────────────────────────────────┐
│           远程开机原理                 │
├───────────────────────────────────────┤
│                                       │
│   手机 ──→ 向日葵服务器 ──→ 开机棒    │
│                              │        │
│                              ↓        │
│                           电脑开机    │
└───────────────────────────────────────┘
```

### 免费版限制

- 每月 40 小时免费时长
- 画质有限制
- 广告较多

### 优缺点

**优点**：
- **远程开机**功能强大
- 老牌软件，稳定性好
- 支持多平台

**缺点**：
- 免费版广告多
- 历史上有过安全争议（明文传输密钥）
- 界面略显陈旧

### 适用场景

- **需要远程开机**：电脑平时关机，需要时再开
- **企业批量管理**：有企业版解决方案

## RustDesk：开源界的新星

RustDesk 是一款开源的远程桌面软件，可以使用公共服务器，也可以**自建服务器**实现完全自主可控。

### 为什么推荐 RustDesk

1. **完全开源**：代码透明，安全可审计
2. **无广告**：清爽的使用体验
3. **可自建**：数据不经过第三方
4. **全平台**：Windows、macOS、Linux、iOS、Android、Web

### 下载安装

访问 [RustDesk 官网](https://rustdesk.com/) 或 [GitHub Release](https://github.com/rustdesk/rustdesk/releases) 下载。

### 使用公共服务器（快速体验）

默认情况下，RustDesk 使用官方公共服务器：

1. 安装并启动 RustDesk
2. 记下你的 ID
3. 在另一台设备输入 ID 和密码连接

```
┌─────────────────────────────────┐
│  RustDesk                       │
├─────────────────────────────────┤
│  你的 ID: 123456789             │
│  一次性密码: ******             │
│                                 │
│  输入远程ID: [          ]       │
│              [连接]             │
└─────────────────────────────────┘
```

### 切换到自建服务器

如果你有自己的 VPS，强烈建议自建服务器：

1. 在 VPS 上部署 RustDesk Server（见第3篇教程）
2. 获取服务器地址和密钥
3. 在客户端设置中填入：
   - 设置 → 网络 → ID/中继服务器
   - 填入服务器地址和 Key

### 优缺点

**优点**：
- **开源免费**，无任何限制
- **可自建服务器**，数据自主可控
- 无广告，界面清爽
- 跨平台支持好

**缺点**：
- 公共服务器不如商业软件稳定
- 自建需要 VPS 成本
- 功能相对基础（无远程开机等）

### 适用场景

- **注重隐私**：数据不想经过第三方
- **有技术能力**：愿意自建服务器
- **长期使用**：一次部署，永久免费

## 横向对比测试

在相同网络环境下（控制端：上海移动 100M；被控端：北京联通 200M），对三款软件进行测试：

### 延迟测试

| 软件 | 平均延迟 | 最低延迟 | 最高延迟 |
|------|----------|----------|----------|
| ToDesk | 12ms | 5ms | 28ms |
| 向日葵 | 25ms | 15ms | 45ms |
| RustDesk (公共) | 35ms | 20ms | 80ms |
| RustDesk (自建) | 8ms | 3ms | 15ms |

> RustDesk 自建服务器延迟最低，取决于 VPS 的位置和带宽。

### 画质对比

| 软件 | 最高分辨率 | 最高帧率 | 编码 |
|------|------------|----------|------|
| ToDesk (免费) | 1080P | 30fps | H.264 |
| ToDesk (付费) | 4K | 144fps | H.265 |
| 向日葵 (免费) | 720P | 30fps | H.264 |
| RustDesk | 原生分辨率 | 60fps | VP9/AV1 |

### 安全性对比

| 软件 | 加密方式 | 数据流向 | 代码审计 |
|------|----------|----------|----------|
| ToDesk | 端到端加密 | 经 ToDesk 服务器 | 闭源 |
| 向日葵 | AES-256 | 经向日葵服务器 | 闭源 |
| RustDesk | 端到端加密 | 可完全自主 | 开源 |

**安全性排名**：RustDesk (自建) > ToDesk > 向日葵

### 综合评分

| 维度 | ToDesk | 向日葵 | RustDesk |
|------|--------|--------|----------|
| 易用性 | ★★★★★ | ★★★★ | ★★★★ |
| 延迟 | ★★★★★ | ★★★★ | ★★★★★ (自建) |
| 画质 | ★★★★★ | ★★★ | ★★★★ |
| 安全性 | ★★★★ | ★★★ | ★★★★★ |

## 我的推荐

根据不同需求，我的推荐如下：

### 小白用户 → ToDesk

- 开箱即用，无需配置
- 国内延迟低，体验好
- 免费版每月 300 分钟，偶尔使用足够

### 需要远程开机 → 向日葵

- 独有的远程开机功能
- 配合开机棒/插座使用

### 注重隐私 → RustDesk 自建

- 数据完全自主可控
- 无使用时长限制
- 需要一台 VPS（成本约 50元/月）

### 临时使用 → RustDesk 公共服务器

- 完全免费，无需注册
- 偶尔使用体验不错

## 常见问题

### Q: 哪个软件连接最稳定？

A: 商业软件（ToDesk、向日葵）通常更稳定，因为有专业运维团队。RustDesk 自建的稳定性取决于你的 VPS 质量。

### Q: 哪个软件最安全？

A: 从技术角度，RustDesk 自建服务器最安全，因为数据不经过任何第三方，且代码开源可审计。

### Q: 免费版够用吗？

A: 看使用频率。偶尔远程（每周 1-2 次，每次几分钟）免费版完全够用。频繁使用建议付费或自建 RustDesk。

### Q: 手机能用吗？

A: 三款软件都支持手机客户端（iOS/Android），可以用手机控制电脑。
