前两篇文章我们了解了神经网络的结构：从感知机到多层网络，从激活函数到前向传播。但有一个核心问题还没回答：**网络的权重是怎么来的？**本文将揭开神经网络"学习"的秘密。

## "学习"的本质

### 什么是神经网络的"学习"

神经网络的"学习"其实就是**调整权重和偏置，让输出更接近正确答案**。

```
初始状态：
  输入: 图片 → 网络(随机权重) → 输出: 90% 是狗

期望输出：
  输入: 图片 → 网络(??权重??) → 输出: 99% 是猫

学习过程：
  不断调整权重，让"狗"的预测变成"猫"的预测
```

### 学习的三个核心问题

1. **如何衡量"错多少"？** → 损失函数
2. **如何知道往哪个方向调？** → 梯度
3. **如何高效计算所有参数的梯度？** → 反向传播

---

## 损失函数：衡量"错多少"

### 什么是损失函数

**损失函数（Loss Function）** 是一个数学函数，用来衡量网络预测值和真实值之间的差距。

```
损失 = 损失函数(预测值, 真实值)

损失越小 → 预测越准确
损失为0 → 完美预测
```

### 常见损失函数

**均方误差（MSE）**：用于回归问题

```
MSE = (预测值 - 真实值)² 的平均值

例子：预测房价
  真实: 100万    预测: 90万
  损失: (100-90)² = 100

  真实: 100万    预测: 99万
  损失: (100-99)² = 1

损失从100降到1，说明预测更准了
```

**交叉熵损失（Cross-Entropy）**：用于分类问题

```
交叉熵 = -Σ 真实概率 × log(预测概率)

例子：判断是否是猫（二分类）
  真实: 是猫(1)    预测: 80%是猫
  损失: -1×log(0.8) ≈ 0.22

  真实: 是猫(1)    预测: 99%是猫
  损失: -1×log(0.99) ≈ 0.01

损失从0.22降到0.01，预测更准了
```

### 直觉理解

把损失想象成"山的高度"：

```
      损失(高度)
        ↑
        │    ╱╲
        │   ╱  ╲
        │  ╱    ╲     ╱╲
        │ ╱      ╲   ╱  ╲
        │╱        ╲_╱    ╲
        └──────────────────→ 权重

目标：找到山谷（损失最低点）
方法：从当前位置往下坡方向走
```

## 梯度下降：找到下坡方向

### 什么是梯度

**梯度（Gradient）** 是多维空间中"最陡上升方向"的向量。

```
单变量情况（导数）：
  函数 f(x) = x²
  导数 f'(x) = 2x

  在 x=3 处，导数 = 6（正值，说明往右是上坡）
  在 x=-2 处，导数 = -4（负值，说明往右是下坡）

多变量情况（梯度）：
  函数 f(x,y)
  梯度 = [∂f/∂x, ∂f/∂y]  （各方向的导数组成的向量）
```

### 梯度下降的核心思想

既然梯度指向上坡方向，那**负梯度就指向下坡方向**：

```
新位置 = 当前位置 - 学习率 × 梯度

步骤：
1. 计算当前位置的梯度
2. 往负梯度方向走一小步
3. 重复直到到达谷底
```

### 直观示例

假设损失函数是 L(w) = w²，我们要找最小值点：

```
初始位置: w = 4
学习率: η = 0.1

第1步:
  梯度 = 2w = 8
  新位置: w = 4 - 0.1×8 = 3.2

第2步:
  梯度 = 2×3.2 = 6.4
  新位置: w = 3.2 - 0.1×6.4 = 2.56

第3步:
  梯度 = 2×2.56 = 5.12
  新位置: w = 2.56 - 0.1×5.12 = 2.048

... 继续迭代 ...

最终: w → 0（最小值点）
```

### 学习率的作用

**学习率（Learning Rate）** 决定每一步走多远：

```
学习率太大:                学习率太小:
    ↑                          ↑
    │  ←→←→                    │  ←←←←←←←
    │ ╱    ╲                   │ ╱      ╲
    │╱      ╲                  │╱        ╲
    └────────→                 └──────────→
  跳来跳去，无法收敛           太慢，需要很多步

适中的学习率:
    ↑
    │  ←←←
    │ ╱   ╲
    │╱     ╲
    └───────→
  稳定下降到最低点
```

## 反向传播：高效计算梯度

### 问题：参数太多怎么办

现代神经网络可能有数百万个参数。如何高效计算每个参数的梯度？

```
简单网络示例：
  输入(2) → 隐藏层(3) → 输出(1)

  参数数量：
    W1: 2×3 = 6
    b1: 3
    W2: 3×1 = 3
    b2: 1
    总共: 13 个参数

如果分别计算每个参数的梯度：
  每个参数需要两次前向传播
  13 × 2 = 26 次前向传播

反向传播只需要：
  1 次前向传播 + 1 次反向传播
```

### 反向传播的核心：链式法则

**链式法则** 让我们可以从后往前传递梯度：

```
假设有函数组合: y = f(g(x))

链式法则:
  dy/dx = dy/dg × dg/dx

例子：
  g(x) = 2x + 1
  f(g) = g²
  y = f(g(x)) = (2x+1)²

  dg/dx = 2
  df/dg = 2g
  dy/dx = 2g × 2 = 4(2x+1)
```

### 反向传播的直觉

把网络想象成一系列"加工站"：

```
前向传播：原料从左到右加工
                →
输入 → [层1] → [层2] → [层3] → 输出
              →

反向传播：误差从右到左传递
                ←
输入 ← [层1] ← [层2] ← [层3] ← 损失
              ←

每个加工站收到来自下游的"投诉"（梯度），
据此调整自己的参数
```

### 反向传播过程示意

以简单网络为例：

```
网络: x → [W1,ReLU] → h → [W2,Sigmoid] → y → Loss

前向传播:
  z1 = W1 × x
  h = ReLU(z1)
  z2 = W2 × h
  y = Sigmoid(z2)
  L = Loss(y, target)

反向传播（从后往前）:

  ∂L/∂y = ∂Loss/∂y                    (损失对预测的导数)
     ↓
  ∂L/∂z2 = ∂L/∂y × ∂y/∂z2             (乘以 Sigmoid 导数)
     ↓
  ∂L/∂W2 = ∂L/∂z2 × h                 (得到 W2 的梯度！)
  ∂L/∂h = ∂L/∂z2 × W2                 (传给上一层)
     ↓
  ∂L/∂z1 = ∂L/∂h × ∂h/∂z1             (乘以 ReLU 导数)
     ↓
  ∂L/∂W1 = ∂L/∂z1 × x                 (得到 W1 的梯度！)
```

关键在于：**每一层只需要知道来自下一层的梯度，就能计算自己参数的梯度**。

## 完整训练流程

把前面的内容组合起来，就是神经网络的完整训练流程：

```
┌─────────────────────────────────────────────────┐
│                  训练循环                        │
│                                                  │
│  for 每个 epoch:                                 │
│      for 每个 batch 的数据:                      │
│                                                  │
│          ┌─────────────────────┐                │
│          │    1. 前向传播      │                │
│          │   输入 → 网络 → 预测  │                │
│          └──────────┬──────────┘                │
│                     ↓                           │
│          ┌─────────────────────┐                │
│          │   2. 计算损失       │                │
│          │  损失 = L(预测, 真实) │                │
│          └──────────┬──────────┘                │
│                     ↓                           │
│          ┌─────────────────────┐                │
│          │   3. 反向传播       │                │
│          │  计算每个参数的梯度  │                │
│          └──────────┬──────────┘                │
│                     ↓                           │
│          ┌─────────────────────┐                │
│          │   4. 更新参数       │                │
│          │  参数 -= 学习率×梯度  │                │
│          └─────────────────────┘                │
│                                                  │
└─────────────────────────────────────────────────┘
```

### 关键术语

| 术语 | 含义 |
|------|------|
| **Epoch** | 完整遍历一次训练数据 |
| **Batch** | 一次处理的数据子集 |
| **迭代（Iteration）** | 一次参数更新 |
| **学习率** | 每次更新的步长 |

### 伪代码

```python
def train(network, data, epochs, learning_rate):
    for epoch in range(epochs):
        total_loss = 0

        for batch_x, batch_y in data:
            # 1. 前向传播
            predictions = network.forward(batch_x)

            # 2. 计算损失
            loss = compute_loss(predictions, batch_y)
            total_loss += loss

            # 3. 反向传播
            gradients = network.backward(loss)

            # 4. 更新参数
            for param, grad in zip(network.parameters, gradients):
                param -= learning_rate * grad

        print(f"Epoch {epoch}: Loss = {total_loss}")
```

## 训练中的常见问题

### 梯度消失

```
问题：梯度在反向传播时越来越小

  层1 ← 0.9 × 层2 ← 0.9 × 层3 ← 0.9 × 输出
       ↓
  0.9³ = 0.729  (还好)

  如果有10层：
  0.9¹⁰ = 0.35  (梯度变得很小)

  如果有100层：
  0.9¹⁰⁰ ≈ 0    (几乎没有梯度了)

结果：前面的层几乎学不到东西
```

**解决方案**：使用 ReLU 激活函数、残差连接等技术。

### 梯度爆炸

```
问题：梯度在反向传播时越来越大

  如果每层梯度是 1.1：
  1.1¹⁰⁰ ≈ 13780  (巨大的梯度)

结果：参数更新过大，训练不稳定
```

**解决方案**：梯度裁剪、归一化等技术。

### 局部最小值

```
      损失
        ↑
        │    ╱╲
        │   ╱  ╲     全局最小
        │  ╱    ╲   ╱     ↓
        │ ╱      ╲_╱
        │╱    ↑
        └─────局部最小───────→ 参数

可能困在局部最小值，无法到达全局最小值
```

**解决方案**：动量优化器、随机初始化多次尝试等。

## 与 Embedding 的关系

现在你能理解 Word2Vec 是如何训练的了：

```
Word2Vec 训练过程：

1. 前向传播：
   词"苹果" → 向量 → 预测周围词

2. 计算损失：
   预测的周围词 vs 真实的周围词
   损失 = 交叉熵

3. 反向传播：
   计算词向量的梯度

4. 更新参数：
   调整词向量，使得相关词的向量更近

重复这个过程，词向量逐渐学会语义关系
```

这正是 [Embedding 系列文章](/posts/embedding-why-similar/) 中提到的 Skip-gram 训练过程！

## 总结

本文介绍了神经网络"学习"的核心机制：

**损失函数**：
- 衡量预测值和真实值的差距
- MSE 用于回归，交叉熵用于分类

**梯度下降**：
- 沿着损失下降最快的方向更新参数
- 学习率控制每步更新的幅度

**反向传播**：
- 利用链式法则高效计算所有参数的梯度
- 从输出层向输入层逐层传递梯度

**完整流程**：
- 前向传播 → 计算损失 → 反向传播 → 更新参数

理解这些概念后，你就掌握了神经网络训练的核心原理。下一篇文章，我们将看看如何用神经网络处理序列数据（如文本），引入 RNN 和 LSTM。
