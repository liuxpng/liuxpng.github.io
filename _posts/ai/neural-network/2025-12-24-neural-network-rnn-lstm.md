前面我们学习了基础神经网络：多层感知机、激活函数、反向传播。但这些网络有一个问题——它们只能处理**固定长度**的输入。当我们要处理文本、语音、时间序列等**可变长度**的序列数据时，需要新的架构。本文将介绍 RNN 和 LSTM。

## 普通神经网络的局限

### 问题：输入必须固定长度

多层感知机（MLP）的输入层神经元数量是固定的：

```
MLP 结构：
  输入(10维) → 隐藏层 → 输出

问题：如何处理不同长度的句子？

"我爱你"     → 3个词
"今天天气真好" → 4个词
"这是一个测试句子" → 5个词

无法直接输入 MLP！
```

### 常见的"变通"方法

**方法1：截断/填充到固定长度**

```
设定最大长度 = 5

"我爱你"     → [我, 爱, 你, PAD, PAD]
"今天天气真好" → [今天, 天气, 真, 好, PAD]

问题：
- 浪费计算资源（PAD 不携带信息）
- 长句子被截断，丢失信息
```

**方法2：用统计特征**

```
句子 → [词数, 平均词长, 特定词出现次数, ...]

问题：
- 丢失词序信息
- "狗咬人" 和 "人咬狗" 可能特征相同
```

这些方法都不理想。我们需要一种能**天然处理序列**的网络架构。

---

## RNN：让网络有"记忆"

### 核心思想

**循环神经网络（RNN, Recurrent Neural Network）** 的核心思想是：

> 处理序列的每一步时，把之前的信息"记住"，传递给下一步。

```
普通神经网络：
  输入 → 处理 → 输出
  （每次独立，互不影响）

RNN：
  输入1 → 处理 → 记忆 ─┐
                       ↓
  输入2 → 处理 → 记忆 ─┐  （记忆传递给下一步）
                       ↓
  输入3 → 处理 → 输出    （利用之前的记忆）
```

### RNN 的结构

```
展开后的 RNN：

        h₀         h₁         h₂         h₃
         │          │          │          │
         ↓          ↓          ↓          ↓
        ┌─┐        ┌─┐        ┌─┐        ┌─┐
  x₁ →  │A│  ───→  │A│  ───→  │A│  ───→  │A│  → 输出
        └─┘        └─┘        └─┘        └─┘
         ↓          ↓          ↓          ↓
        y₁         y₂         y₃         y₄

A: 同一个神经网络（参数共享）
h: 隐藏状态（记忆）
x: 输入
y: 输出
```

同一个网络 A 被重复使用，但每次都接收：
1. 当前时刻的输入 x
2. 上一时刻的隐藏状态 h

### RNN 的计算过程

```
在时刻 t：

隐藏状态更新:
  hₜ = tanh(Wₕ × hₜ₋₁ + Wₓ × xₜ + b)

输出计算:
  yₜ = Wᵧ × hₜ

其中：
  Wₕ: 隐藏状态的权重（自己跟自己）
  Wₓ: 输入的权重
  Wᵧ: 输出的权重
  b: 偏置
```

### 用 RNN 处理句子

以情感分析为例：

```
句子："今天 天气 很好"

时刻1：输入"今天"
  h₁ = tanh(W × h₀ + W × "今天")
  h₁ 包含了"今天"的信息

时刻2：输入"天气"
  h₂ = tanh(W × h₁ + W × "天气")
  h₂ 包含了"今天"+"天气"的信息

时刻3：输入"很好"
  h₃ = tanh(W × h₂ + W × "很好")
  h₃ 包含了整个句子的信息

最终：用 h₃ 预测情感（正面/负面）
```

## RNN 的问题：长期依赖

### 什么是长期依赖

```
句子："我出生在法国，... (省略100个词) ...，所以我说法语"

要预测"法语"，需要记住100个词之前的"法国"

但 RNN 的记忆会随时间"衰退"
```

### 梯度消失问题

为什么会记忆衰退？因为反向传播时梯度会指数级衰减：

```
假设有100个时间步：

梯度从 t=100 传到 t=1：
  梯度 × W × W × W × ... × W  (乘100次)

如果 |W| < 1：
  0.9¹⁰⁰ ≈ 0.00003  (几乎为0)

如果 |W| > 1：
  1.1¹⁰⁰ ≈ 13780    (梯度爆炸)
```

结果：
- 梯度消失 → 无法学习长期依赖
- 梯度爆炸 → 训练不稳定

### 直觉理解

```
想象"传话游戏"：

第1人 → 第2人 → 第3人 → ... → 第100人

每次传话都有轻微变形，
传到第100人时，原话已经面目全非

RNN 的记忆传递也是如此
```

## LSTM：更好的记忆机制

### 核心思想

**长短期记忆网络（LSTM, Long Short-Term Memory）** 在 1997 年被提出，解决了 RNN 的长期依赖问题。

核心创新：**引入"门控"机制，让网络学会"选择性记忆"**

```
RNN：
  所有信息都通过 tanh 压缩，逐渐衰减

LSTM：
  有专门的"记忆通道"，信息可以直接通过
  用"门"控制什么信息进入/保留/输出
```

### LSTM 的三个门

```
LSTM 单元结构：

          ┌──────────────────────────────────────┐
          │                                       │
          │    遗忘门     输入门      输出门       │
          │      f         i           o          │
          │      ↓         ↓           ↓          │
    ─────→│─→ 决定遗忘 → 决定输入 → 决定输出 ─→────│→ hₜ
    cₜ₋₁  │      ↓         ↓           ↓          │   cₜ
          │      └────→ cₜ ←────┘      │          │
          │                            ↓          │
    ─────→│──────────────────────────→ ×  ────────│→
    hₜ₋₁  │                                       │
          └───────────────────────────────────────┘
                            ↑
                           xₜ
```

**1. 遗忘门（Forget Gate）**

```
"过去的哪些信息应该忘掉？"

fₜ = σ(Wf × [hₜ₋₁, xₜ] + bf)

输出 0~1 之间的值：
  0 = 完全忘记
  1 = 完全保留
```

**2. 输入门（Input Gate）**

```
"新信息的哪些部分应该记住？"

iₜ = σ(Wi × [hₜ₋₁, xₜ] + bi)
c̃ₜ = tanh(Wc × [hₜ₋₁, xₜ] + bc)

新的候选记忆 c̃ₜ 被输入门 iₜ 过滤
```

**3. 输出门（Output Gate）**

```
"记忆中的哪些部分应该输出？"

oₜ = σ(Wo × [hₜ₋₁, xₜ] + bo)
hₜ = oₜ × tanh(cₜ)

最终输出 hₜ 是过滤后的记忆
```

### 记忆更新过程

```
核心公式：

cₜ = fₜ × cₜ₋₁ + iₜ × c̃ₜ

翻译成人话：
  新记忆 = 遗忘门 × 旧记忆 + 输入门 × 候选新记忆

例子：
  旧记忆：[法国, 天气好, 昨天...]
  遗忘门：[1.0, 0.1, 0.1]  (保留"法国"，忘掉其他)
  新信息："说法语"
  输入门：[1.0]  (记住这个新信息)

  新记忆 = [法国] + [说法语]
```

### 为什么 LSTM 能解决长期依赖

```
关键：记忆通道 c 的梯度可以"直接传递"

RNN:
  h₁ → tanh → h₂ → tanh → h₃ → tanh → h₄
       ×            ×            ×
  梯度经过多次 tanh 导数相乘，逐渐消失

LSTM:
  c₁ ─── × f ──→ c₂ ─── × f ──→ c₃ ─── × f ──→ c₄
             +           +           +
  如果遗忘门 f ≈ 1，梯度几乎不衰减！
```

## GRU：简化版的 LSTM

2014 年提出的 **GRU（Gated Recurrent Unit）** 是 LSTM 的简化版：

```
GRU 只有两个门：

1. 重置门（Reset Gate）: 决定如何结合新输入和旧记忆
2. 更新门（Update Gate）: 决定保留多少旧记忆
```

### LSTM vs GRU

| 对比 | LSTM | GRU |
|------|------|-----|
| 门数量 | 3个 | 2个 |
| 参数量 | 更多 | 更少 |
| 记忆机制 | 分离的 c 和 h | 只有 h |
| 性能 | 通常略好 | 相近，有时更好 |
| 训练速度 | 较慢 | 较快 |

实践中，两者性能通常相近，GRU 更简洁高效。

## RNN 系列的局限

虽然 LSTM/GRU 解决了长期依赖问题，但 RNN 系列仍有根本性局限：

### 1. 顺序计算，无法并行

```
RNN 必须按顺序处理：

h₁ 必须算完 → 才能算 h₂ → 才能算 h₃ → ...

这意味着：
- 100个词的句子需要100步
- 无法利用现代 GPU 的并行计算能力
- 训练速度慢
```

### 2. 距离仍然影响关联

```
即使用 LSTM，距离越远的词，关联越弱

句子："我在巴黎出生，后来去了纽约，又去了东京，
      最后定居伦敦，所以我说法语"

"巴黎"和"法语"相隔太远，关联仍然较弱
```

### 3. 无法真正"看到"全局

```
处理第10个词时，只能看到前9个词的"压缩表示"

无法直接看到第2个词的原始信息
必须通过"压缩-传递-解压"的过程
```

这些局限促使研究者提出了新的架构——**Transformer**，它使用 Attention 机制完全取代了循环结构。

---

## 总结

本文介绍了处理序列数据的神经网络：

**RNN**：
- 通过循环结构让网络有"记忆"
- 可以处理变长序列
- 但存在梯度消失/爆炸问题

**LSTM**：
- 引入门控机制解决长期依赖
- 遗忘门、输入门、输出门
- 记忆可以长期保持

**GRU**：
- LSTM 的简化版
- 性能相近，更加高效

**RNN 系列的局限**：
- 顺序计算，无法并行
- 距离仍影响关联强度
- 无法真正看到全局
